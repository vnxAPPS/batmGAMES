# vnxLIGHT — фонарик

Фонарик в фирменном стиле vnxAPPS: луч света растёт из светящейся кромки,
в нём плывут «матричные» символы, яркость меняется пальцем по полоске, свет
разгорается и гаснет плавно. Без рекламы, без сети, без сбора данных.

## Как устроено

| Путь | Что |
|---|---|
| `android/.../MainActivity.kt` | мост к вспышке: `CameraManager.setTorchMode`, на Android 13+ — `turnOnTorchWithStrengthLevel` (реальная яркость светодиода); следит за переключением из шторки |
| `lib/torch.dart` | состояние: яркость 0..1 (0 — выключено), ступени вспышки, вызовы по одному |
| `lib/light_screen.dart` | экран: фон, корпус лампы, луч, полоска, кнопка |
| `lib/widgets/beam.dart` | луч и плывущие символы (CustomPainter) |
| `lib/widgets/controls.dart` | полоска яркости и кнопка |
| `test/` | логика вспышки на подменённом канале и раскладка на трёх экранах |
| `tool/make_icons.py` | значки, значок 512 и обложка для Play |
| `tool/emulator-smoke.sh` | прогон на эмуляторе со скриншотами |

## Поведение

- Кнопка включает прежнюю яркость (по умолчанию полную) и выключает.
- Полоска: вверх ярче, до самого низа — выключено.
- Если вспышка умеет ступени (Android 13+, многие Xiaomi, Samsung, Pixel),
  полоска меняет яркость светодиода; иначе вспышка просто вкл/выкл, а
  полоска меняет только луч на экране.
- Нет вспышки — светит экран, один раз всплывает подсказка.
- Разрешение CAMERA не нужно, INTERNET тоже (CI проверяет).

## Инварианты

- Имя пакета `com.vnxapps.light`: после первой загрузки в Play не меняется.
- Нет разрешения INTERNET: на этом держится анкета безопасности данных.
