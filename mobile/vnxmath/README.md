# vnxMATH — математические загадки

Игра-головоломка: найти закономерность и вписать число вместо «?». 60 уровней
пяти видов: числовые ряды, пирамиды сумм, уравнения с фигурами, таблицы 3×3,
треугольники. Без рекламы, без регистрации, без интернета, без сбора данных.

## Устройство

| Путь | Что |
|---|---|
| `lib/puzzles/model.dart` | типы задач и правила; у каждого правила подсказка на двух языках |
| `lib/puzzles/levels.dart` | 60 уровней по возрастанию сложности |
| `lib/screens/` | главный экран, список уровней, экран задачи |
| `lib/widgets/` | фон, стеклянные карточки, кнопки, отрисовка задач |
| `test/levels_test.dart` | каждый уровень проверяется исполнением правила, плюс однозначность ответа и решаемость пирамид |
| `test/widget_test.dart` | прохождение уровня, подсказка, язык, раскладка всех уровней на трёх размерах экрана |
| `tool/make_icons.py` | значки приложения, значок 512 и обложка для Play |
| `tool/emulator-smoke.sh` | прогон на эмуляторе в CI со скриншотами |
| `../../.github/workflows/vnxmath-android.yaml` | тесты → подписанная сборка → эмулятор |
| `store/` | картинки и тексты для страницы в Play |

## Сборка и проверка

```bash
flutter pub get
flutter analyze
flutter test
flutter build appbundle --release
```

CI (`.github/workflows/vnxmath-android.yaml` в корне репозитория) делает то
же на каждый пуш в `mobile/vnxmath/`, подписывает сборку общим ключом
загрузки мобильных игр (секреты `ANDROID_*`, см. `mobile/SIGNING.md`) и
проходит первый уровень на эмуляторе. Без секретов сборка подписывается отладочным ключом: в неё можно
играть, но в Play её не загрузить.

## Инварианты

- **Имя пакета `com.vnxapps.math`.** После первой загрузки в Play его не
  сменить.
- **Нет разрешения INTERNET.** На этом держится ответ «данные не собираются» в
  анкете безопасности данных. CI падает, если разрешение появится.
- **Каждый новый уровень — с тестом.** Он добавляется в `levels.dart`, а
  `levels_test.dart` проверит его сам, если тип задачи уже известен.
