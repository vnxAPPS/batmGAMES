# Мобильные игры batmGAMES

Нативные приложения для Google Play. Каждая игра — отдельный проект в своей
папке, со своим конвейером в `.github/workflows/<игра>-android.yaml`,
который срабатывает только на изменения в этой папке.

| Папка | Игра | Стек |
|---|---|---|
| `vnxmath/` | vnxMATH — математические загадки, 60 уровней | Flutter |
| `vnxlight/` | vnxLIGHT — фонарик с плавной яркостью | Flutter + Kotlin (вспышка) |

Ключ загрузки общий для всех игр: [SIGNING.md](SIGNING.md).

## Как добавить игру

1. Новый проект в `mobile/<игра>/`, со своим `applicationId`.
2. Конвейер: копия `.github/workflows/vnxmath-android.yaml` с заменой пути
   и имени пакета.
3. Тесты, которые гоняет конвейер, и прогон на эмуляторе — до первой загрузки
   в Play, а не после.
