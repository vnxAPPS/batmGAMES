### 2026-09-12 17:30: Jekyll блокирует _platform и _games
**Проблема:** Все файлы из `_platform/` и `_games/` возвращали 404  
**Причина:** GitHub Pages по умолчанию использует Jekyll, который игнорирует директории с `_`  
**Симптомы:**
- Platform SDK (platform.js) недоступен
- Стили (styles.css) не загружаются
- Игровые модули (.js) не работают
- Все игры показывают пустой экран или ошибки в консоли

**Исправлено:** Commit 2f1924d - добавлен `docs/.nojekyll`  
**Тест:** Запустить `bash test-platform.sh` - все должно быть зелёным  
**Важно:** После любых изменений структуры - проверять наличие `.nojekyll`

## Как репортить баги

1. **Воспроизведи баг 2 раза** — убедись что стабильно повторяется
2. **Открой DevTools** — скопируй console errors/warnings
3. **Сделай скриншот** — если визуальная проблема
4. **Добавь в этот файл** используя шаблон выше
5. **Коммит:** `git add ISSUES.md && git commit -m "Report: [краткое описание]"`
6. **Пуш:** `git push origin main`
7. **Напиши в команду** — пинг ответственного разработчика
