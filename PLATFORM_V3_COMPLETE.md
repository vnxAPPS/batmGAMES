## 🎮 Как это работает

### Для игрока:

1. Открывает: `https://vnxapps.github.io/batmGAMES/play.html?game=runner`
2. Видит **Start Screen** с персонажем, названием, рекордом
3. Нажимает **ИГРАТЬ** (Liquid Glass кнопка)
4. Играет
5. При Game Over видит **Game Over Screen** с результатом
6. Может нажать **ЕЩЁ РАЗ** или **В МЕНЮ**

**Во всех играх одинаково!**

### Для разработчика:

1. Создаёт файл `_games/my-game.js`
2. Реализует Game API:
   ```javascript
   export default {
     meta: { slug, title, description },
     init(canvas, platform) {},
     start() {},
     stop() {},
     update() {},
     render() {},
   }
   ```
3. Добавляет карточку в главное меню
4. Готово! Платформа автоматически:
   - Покажет Start Screen
   - Отрисует персонажа
   - Обработает Game Over
   - Сохранит рекорд

## 🚀 Platform API

Разработчик получает доступ к:

```javascript
// Обновить счёт
platform.updateScore(100);

// Завершить игру
platform.gameOver(finalScore);

// Отрисовать персонажа (единообразно!)
platform.renderCharacter(ctx, x, y, size);

// Haptic feedback
platform.haptic('success');

// Данные игрока
const user = platform.user;
// { id, username, character: {...} }
```

## 📊 Преимущества

### 1. Единообразие
- Все игры выглядят одинаково
- Персонаж рендерится идентично
- Одни и те же кнопки, экраны, анимации

### 2. Простота добавления игр
- Разработчик пишет только логику игры
- UI создаётся автоматически
- 200 строк кода вместо 500+

### 3. Централизованное обновление
- Изменил `platform.js` → все игры обновились
- Поменял дизайн кнопок → все игры сразу новые
- Исправил баг → один файл вместо 9

### 4. Переиспользование кода
- Персонаж: один рендерер для всех игр
- Рекорды: единая логика
- Haptic: единый API
